# DAY ONE BELAJAR JS 
Di hari pertama belajar js gw gak banyak belajar, gw cuman belajar ES6+ sampai paham.
apa saja yang gw pelajar ? 
yang pertama gw belajar tentang .map, .filter, dan .reduce 
apa sih pengertian dari ketika itu ? 
jadi pengertian dari ketiganya yaitu sebagai berikut: 
- .map() : Digunakan untuk mengubah setiap elemen dalam array menjadi nilai baru. Menghasilkan array baru dengan panjang yang sama.
- .filter() : Digunakan untuk mengambil elemen array yang memenuhi kondisi tertentu saja. Menghasilkan array baru.
- .reduce() : Digunakan untuk mengolah seluruh isi array menjadi satu nilai tunggal (misal: menghitung total harga, rata-rata, atau mengelompokkan data).
